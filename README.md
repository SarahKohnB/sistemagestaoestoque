# Sistema de Gestão de Estoque

Sistema web desenvolvido para controle de estoque de uma indústria de embalagens.

## Tecnologias utilizadas

- Python
- SQLite
- HTML
- CSS
- Visual Studio Code

## Como visualizar os documentos no VScode

### 1. Instalar a extensão:

**Office Viewer**

## Como executar o sistema

### 1. Abrir o projeto

Abra a pasta `sistema` no Visual Studio Code.

### 2. Abrir o terminal

No VS Code, abra:

**Terminal → Novo Terminal**

### 3. Executar o sistema

No terminal, digite:

```bash
python app.py
